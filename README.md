# Autumn Lee | Data Analyst Portfolio

A simple personal portfolio hosted with GitHub Pages, showcasing analytics, machine learning, and geospatial projects.

## Files

- `index.html`: portfolio content
- `style.css`: styling
- `assets/`: optional images, screenshots, and public CV

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, and the `assets` folder to the root of the repository. Commit the files to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then save.
5. Visit `https://YOUR_USERNAME.github.io/` after deployment finishes.

## Customize before sharing

- Replace the placeholder GitHub and LinkedIn links in `index.html`.
- Review all descriptions and ensure they accurately reflect your work.
- Replace “Repository coming soon” with links to public repositories when available.
- Add screenshots to `assets/` and link them from `index.html` if desired.
- Do not upload confidential employer or research data, private contact information, or unpublished project materials.

## Local preview

Open `index.html` in a browser. No installation or build step is required.
